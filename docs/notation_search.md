# Поиск по нотации

Фильтр доступен на странице игрока: `/player/<username>/openings`.

## Ввод

Можно вводить с номерами ходов или без:

```
1.e4 e5 2.Nf3 Nc6
e4 e5 Nf3 Nc6
```

Минимум — 2 полухода.

## Как ищется

1. Запрос нормализуется до SAN-токенов:
   - убираются `1.`, `1...`, комментарии `{...}`, `!?`, NAG, результат;
   - остаются ходы: `e4`, `exd5`, `Nf3`, `O-O`, `e8=Q+`.
2. PGN партии нормализуется так же.
3. Ищется непрерывная последовательность токенов в любом месте партии.

## Результат

- Подсвечивается найденный фрагмент в PGN.
- Кнопка «↗ К ходу» открывает партию на позиции после найденной
  последовательности: `/game/<id>/view?ply=N`.
- Фильтр сохраняется в пагинации и ссылках «популярные дебюты».

## Ограничения

- Это не поиск по позиции/транспозиции, а поиск по последовательности ходов.
- Слишком короткие запросы отклоняются.
