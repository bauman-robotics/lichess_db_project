# Переход по ходам из текста анализа

В тексте анализа SAN-ходы подсвечиваются и, если ход есть в партии,
становятся кликабельными.

## Как определяется позиция

Из `/player/<username>/game/<game_id>/positions` берётся список позиций.
Строится индекс:

- точный ключ: `номер хода + цвет + SAN`;
- список вхождений по SAN.

Правила:

- `8...Bxd4` → точный переход;
- `Bxd4` при единственном вхождении → переход;
- повторяющийся SAN без номера → подсветка без перехода;
- ход, которого нет в партии → стиль «вариант», без перехода.

## UI

- Золотая пунктирная подсветка — ход из партии.
- Активный ход подсвечивается при перелистывании доски.
- Клик по ходу:
  - на странице просмотра — переход к позиции;
  - в модалке анализа — открывается просмотрщик на нужном ходу;
  - в избранном/заметках — переход на страницу партии с `?ply=N`.
- На мобильном доска прокручивается в видимую область.

## Файлы

- `web_app/static/js/analysis_moves.js` — индекс и разметка текста.
- `game_viewer.js` — навигация и активный ход.
- `analysis.js` — модалка анализа.
