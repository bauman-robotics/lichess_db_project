# Заметки к партиям

Заметки хранятся в единой таблице `game_annotations` вместе с избранным.

## Таблица

- `player_username`, `game_id` — первичный ключ.
- `note` — plain text до 2000 символов.
- `is_favorite` — избранное.
- Снимок метаданных партии: дата, соперник, рейтинг, цвет, результат,
  дебют, контроль, число ходов, ссылка.
- `created_at`, `updated_at`.

Избранное — это `is_favorite = TRUE`. Заметку можно поставить любой
партии, даже если она не в избранном. Удаление из избранного заметку
не удаляет.

## UI

- Иконка 📝 в списках: последние игры, фильтр, топ по длине,
  прогресс, избранное и просмотр партии.
- Заполненная иконка 📝 (золотая) — заметка есть.
- Модалка: сохранить, удалить, `Ctrl+Enter`.
- Страница `/notes` — поиск по тексту заметки, игроку, сопернику и дебюту.
- Сортировка: недавно изменённые / дата партии / соперник.

## API

```http
GET   /annotations/<username>/<game_id>
PATCH /annotations/<username>/<game_id>
      {"note": "текст"}
```

Пустая заметка удаляет строку, если партия не в избранном.

## Миграция

```bash
python scripts/migrations/003_unify_annotations.py --status
python scripts/migrations/003_unify_annotations.py --apply
```

`favorite_games` переименовывается в `game_annotations`, существующие
записи получают `is_favorite = TRUE`, заметки сохраняются.
