# Стримеры в поиске

Курируемый список хранится в `config/streamers.yaml` и показывается
отдельной секцией «📺 Стримеры» на странице поиска.

## Формат

```yaml
default_limit: 300

streamers:
  - username: "RebeccaHarris"
    name: "Даниил Народицкий"
    title: "GM"
    limit: 300
    enabled: true
```

- `username` — имя на Lichess, проверяется тем же нормализатором, что и поиск.
- `name` — отображаемое имя рядом с ником.
- `title` — GM / IM / FM; можно оставить пустым.
- `limit` — сколько последних игр скачивать; если не указан, берётся `default_limit`.
- `enabled: false` — временно скрыть стримера.

«Загружен» определяется наличием таблицы `games_<username>`.
Если таблицы нет, карточка показывает «не загружен» и не появляется
в «Моих игроках».

## Импорт

```bash
source venv/bin/activate

# посмотреть план
python scripts/import_streamers.py --dry-run

# загрузить всех, у кого ещё нет таблицы
python scripts/import_streamers.py

# только выбранных
python scripts/import_streamers.py --only RebeccaHarris,EricRosen

# перезагрузить последние игры (дубликаты отбрасываются по game_id)
python scripts/import_streamers.py --refresh --limit 300
```

Скрипт создаёт таблицу `games_<username>` и импортирует PGN через
существующий `ImportManager`. Между стримерами выдерживается пауза
`--delay` (по умолчанию 1 секунда).

## Ограничения

- Скачивается только последние N игр, а не вся история.
- Импорт лучше запускать на сервере из CLI, а не через веб-запрос.
- После импорта список в веб-интерфейсе обновляется в течение ~10 секунд
  (кэш списка игроков).
