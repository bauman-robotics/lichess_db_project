♟️ Lichess Analyzer

Анализ шахматных партий с Lichess: статистика, дебюты, разбор через DeepSeek и просмотр партий с доской.

🎬 Видеопрезентация

Обзор функционала: от поиска игрока до разбора партии.

⚙️ Что умеет проект
🔍 Поиск и загрузка игрока

Введите имя игрока Lichess — проект скачает до 1000 (или больше) партий и сохранит в локальную БД.

📊 Полная статистика

Победы/поражения/ничьи, рейтинг, точность, соперники, период, топ дебютов, прогресс рейтинга.

📈 Разделы по игроку
  • Игры — список партий + обновление
  • Прогресс — график рейтинга + рейтинговая статистика
  • Контроль — по контролю времени
  • Длина — распределение + топ-10 коротких/длинных
  • Дебюты — топ дебютов
  • Партии по дебютам — фильтр по названию/результату/цвету
♟️ Просмотр партии
  • Доска с координатами и подсветкой последнего хода
  • Список ходов, навигация: ◀ ▶ ⏮ ⏭ 🔄 ⏯
  • Клавиатура: ← → Space Home End
  • Адаптивный layout для десктопа и мобильного
  • Ссылка на партию — можно делиться
🤖 AI-разбор через DeepSeek
  • Разбор партии с указанием ошибок и ключевых ходов
  • Поддержка нескольких промптов (game_analysis, game_analysis_sarcastic)
  • Режимы: API (официальный DeepSeek) или Bridge (бесплатная обёртка)
  • Отключение reasoning — быстро и дёшево
🔄 Обновление игр

Кнопка «Обновить игры» дозагружает только новые партии с Lichess (по дате последней игры в БД). Дубликаты пропускаются через SAVEPOINT.

📱 Мобильная адаптация

Компактные карточки игр, короткие названия вкладок, скролл страницы + внутренние скроллы вкладок, фиксированный футер с табами.

⚡ Производительность

Локальная БД (PostgreSQL), gunicorn + nginx, кеш CSS/JS по версии, адаптивный размер доски.

🚀 Как начать
  1. Введите имя игрока на странице 🔍 Поиск.
  2. Дождитесь загрузки партий — проект скачает игры с Lichess и сохранит в БД.
  3. Смотрите статистику на странице игрока: вкладки «Прогресс», «Контроль», «Длина», «Дебюты».
  4. Откройте партию — клик по 👁 в списке, затем нажимайте 🤖 для AI-разбора.
  5. Обновляйте игры — кнопка «🔄 Обновить игры» дозагрузит новые партии с Lichess.
