# Произношение терминов

## Yandex SpeechKit

Ударение ставится символом `+` **перед ударной гласной**.

### Основной вариант

```text
Л+ичесс
Стокф+иш
Дипс+ик
```

### Lichess: спорное произношение

Если `Л+ичесс` звучит неправильно, тестируем варианты:

```text
Ли sil<[60]> чесс
Ли sil<[80]> чесс
Ли sil<[120]> чесс
Ли-чесс
```

`sil<[t]>` — пауза в миллисекундах. Большая пауза звучит неестественно,
поэтому начинать лучше с 60–80 мс.

### Другие термины

```text
Ан+ализер
Ан+иш Г+ири
Валент+ина Г+унина
эндшп+иль
деб+ют
сант+ипешка
```

## Azure / Google / Polly

Для них нужен SSML с фонемами:

```xml
<phoneme alphabet="ipa" ph="...">Lichess</phoneme>
```

или пользовательский лексикон. Ударение задаётся через IPA, а не символом `+`.

## Edge TTS

Управления ударением нет. Можно только менять скорость, тон и делать
паузы через пунктуацию/разделение слова, но это неполноценная замена.
