## [2026-11-01] iteration 0.4 — обновление на сервере по SSH

Добавлен локальный скрипт обновления: подключается к серверу, загружает
серверный скрипт, делает `git pull`, миграции и перезапуск сервиса.

### Добавлено

- `scripts/deploy/update_remote.py` — локальный SSH-раннер: читает
  `deploy`/`remote.ssh` из `config/secrets.yaml`, поддерживает ключ/пароль,
  `--dry-run`, `--yes`, `--skip-migrations`, `--skip-restart`, `--no-sudo`,
  healthcheck.
- `scripts/deploy/server_update.sh` — серверный скрипт: проверка чистого
  рабочего дерева, `git fetch/pull --ff-only`, `setup_db.py --action create`,
  `systemctl restart`, `is-active`, healthcheck.
- `docs/deployment.md` — настройка, sudoers, примеры запуска и ограничения.
- `config/secrets.yaml.example` — секция `deploy`.

### Изменено

- `README.md` — ссылка на инструкцию по обновлению.

### Исправлено

- `server_update.sh` сам определяет `PROJECT_PATH` по расположению скрипта;
  `USE_SUDO` по умолчанию 0 для root и 1 для остальных.
- Скрипты деплоя получили executable-бит.
- Проверка чистого дерева учитывает только отслеживаемые файлы;
  untracked-файлы (например, `activate.sh`) не блокируют обновление.
- `activate.sh` добавлен в `.gitignore`.
- `web_app/routes.py` получил `from __future__ import annotations` —
  совместимость с Python 3.8/3.9 при аннотациях `str | None` и `list[...]`.
- Healthcheck в `server_update.sh` ждёт до 30 секунд: gunicorn
  поднимается не мгновенно после `systemctl restart`.

## [2026-11-01] iteration 0.3 — доработки веб-интерфейса

Начата итерация улучшений UI: поиск по имени и ссылке на профиль,
список игроков, фильтры и пагинация на дебютах, прогресс по контролям,

### Добавлено

- `docs/specs/ui_improvements_v1.md` — полное ТЗ итерации: решения,
  маршруты, конфиг, мобильные требования, критерии приёмки.

  колонки в таблицах партий; существующие данные не очищаются.

### Шаг 2 — поиск по имени и ссылке на профиль

**Добавлено:**
- `core/utils/lichess.py` — нормализация имени/URL Lichess, безопасные
  имена таблиц и файлов, классификация контроля времени

**Изменено:**

  URL без схемы, trailing slash и query; ошибки показываются под полем.

  имя и кодируют его в URL; имя временного файла безопасно.
- Ретраи Lichess — только для 429/5xx/сетевых ошибок; 404 больше

- `get_safe_table_name` заменяет все недопустимые символы и
  ограничивает длину таблицы 63 символами.

## [2026-10-13] iteration 0.2 — третий промпт анализа: стиль канала «Шахматы — это Круто»

Добавлен **третий вариант промпта** для анализа партий — саркастический
в стиле канала «Шахматы — это Круто». Построен из 30 транскрибаций
видео канала через пайплайн: очистка → маркеры → сводный гайд → промпт.

### Добавлено

**Промпты:**
- `game_analysis_shahmaty_eto_kruto` в `config/deepseek_prompts.yaml` —
  саркастический разбор в стиле канала (метафоры, обороты, юмор).
  В `user_template` добавлен `{style_guide_block}` — вставляется
  полный справочник стиля.
- `config/prompts/extract_markers.txt` — промпт извлечения стилевых
  маркеров из транскрипции (метафоры, юмор, обороты, эмоции).
- `config/prompts/build_style_guide.txt` — промпт свода 30 маркеров
  в единый справочник.

**Скрипты** (`scripts/03_transcript_style/`):
- `01_cleanup_vosk.py` — очистка транскрипций Vosk через flash
  (переоформлен для воспроизводимости).
- `02_extract_markers.py` — извлечение стилевых маркеров из
  `cleaned/*_cleaned.txt` → `markers/*_markers.md` (flash).
- `03_build_style_guide.py` — свод 30 маркеров в единый
  `data/chess_transcripts/style_guide.md` (v4-pro).

**Данные:**
- `data/chess_transcripts/markers/*_markers.md` — 30 файлов
  стилевых маркеров (по одному на транскрибацию).
- `data/chess_transcripts/style_guide.md` — справочник стиля
  (649 строк, ~4200 слов): метафоры по фигурам/действиям/позициям,
  речевые обороты по функциям, приёмы юмора, эмоциональные приёмы,
  тон и атмосфера, готовые фразы-конструкции.

### Изменено

**`services/deepseek_analyzer.py`:**
- `STYLE_GUIDE_FILE` — путь к `style_guide.md`.
- `load_style_guide()` — читает `style_guide.md`, если есть.
- `build_prompt(game, prompts, player_name, style_guide=None)` —
  новый параметр `style_guide`; формирует `{style_guide_block}`.
  **Обратная совместимость:** старые промпты без placeholder
  работают как раньше.
- `analyze_game()` — читает гайд и передаёт в `build_prompt`.
- **Фикс `move_count`:** в БД хранятся **полуходы**, в промпт
  отдаём **полные ходы** (`(plies + 1) // 2`). 57 полуходов → 29 ходов.
- **Фикс `player_color`:** в БД колонка `player_color`, а не `color`.
  Теперь `game.get('color') or game.get('player_color') or '?'`.

**`config/app_config.yaml`:**
- `prompt_key: game_analysis_shahmaty_eto_kruto` (активный промпт).
